# 物种照片来源与许可

每张照片在界面上都显示来源、许可和作者；点击“查看原始页面”可以核对原始记录。

## 说明

- 照片仅用于教学演示，帮助读者建立“这个物种长什么样”的直观印象。
- 转载或二次发布时请保留来源、许可和作者；CC BY-SA / CC BY-NC-SA 要求以相同方式共享。
- 天蓝色链霉菌使用链霉菌属（*Streptomyces*）的菌落照片作为属级代表，界面上已注明。
- 以下物种目前没有可靠且许可清晰的照片，界面显示“还没有照片”，用户可自行补充：Vibrio cholerae、Prochlorococcus marinus、Nitrosopumilus maritimus、Methanobrevibacter smithii、Deinococcus radiodurans、Synechococcus elongatus。
- 用户自行上传的图片不会进入仓库，只保存在上传者浏览器的本地工作区。
